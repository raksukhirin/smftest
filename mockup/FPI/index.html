7 หน้าจอ

แต่ละหน้าทำอะไร — และเปิดดูได้เลย

ทุกการ์ดคลิกเข้าหน้าจอจริงที่ใช้งานได้ ไม่ใช่ภาพนิ่ง

1

Rate Management

คลังเรท

รวมเรทจากทุกสายเรือ/สายการบินไว้ที่เดียว ค้นหาและเทียบราคาข้ามเจ้าได้ทันที พร้อมเตือนล่วงหน้าก่อนเรทหมดอายุ — เลิกรื้ออีเมลและไฟล์เก่า

เปิดหน้าจอ →
2

Quotation Generator

เสนอราคา

ทำใบเสนอราคาได้ในหลักนาที เลือกทางเลือกให้ลูกค้าทั้งแบบประหยัด สมดุล และเร็ว จบด้วยใบเสนอราคาพร้อมพิมพ์ในนามบริษัท

เปิดหน้าจอ →
3

Booking Margin Gate

เคาะกำไร

คำนวณกำไรอัตโนมัติตอนยืนยันงาน งานที่กำไรต่ำกว่าเกณฑ์จะถูกกันไว้ให้ตรวจก่อน พร้อมอธิบายว่ากำไรตกเพราะอะไร — ตลาดขึ้น หรือตั้งราคาต่ำ

เปิดหน้าจอ →
4

Approval Inbox

คิวอนุมัติ

คิวงานรออนุมัติสำหรับหัวหน้า จัดกลุ่มตามเหตุผล (ขาดทุน / ตลาดขึ้น / ราคาต่ำ) อนุมัติทีละใบหรือทั้งชุดได้ในหน้าเดียว

เปิดหน้าจอ →

KB Dashboard

สรุปทั้งคลังในหน้าเดียว — เรทใกล้หมดอายุ ใบเสนอราคาที่เริ่มเสี่ยงเพราะต้นทุนขยับ กำไรเฉลี่ย เลนยอดนิยม และอัตราปิดงาน

เปิดหน้าจอ →

AI Knowledge Search

7

Margin Actualization

กำไรจริง · ปิดวงจร

หลังงานจบและวางบิลแล้ว ระบบอ่านตัวเลขจากบัญชีเดินงานจริง มาแสดงกำไรที่เกิดขึ้นจริง แยกมุมแผนกขายและแผนกคอนโซล แล้ววนกลับไปเทียบกับกำไรที่เคยเคาะไว้ตอนยืนยันงาน — ตอบคำถามที่หกหน้าแรกตอบไม่ได้ ว่างานที่รับไปจริง ๆ จบที่กำไรเท่าไหร่

แยกแผนก ขาย / คอนโซล สิทธิ์การเห็นตามบทบาท เทียบ ประมาณการ ↔ จริง
เปิดหน้าจอ →
คุณค่า

ทำไมถึงต่างจากการทำงานวันนี้

01
ราคากลาง ไม่ใช่ความจำของแต่ละคน

เรททุกเจ้าอยู่ที่เดียว ค้นเจอใน 3 วินาที และเตือนก่อนหมดอายุ — ไม่ต้องรื้ออีเมลหรือถามกันในแชต

02
กำไรถูกเคาะก่อนเสมอ ไม่ใช่รู้ตอนสิ้นเดือน

ทุกงานผ่านการคำนวณกำไรตอนยืนยัน งานเสี่ยงถูกกันขึ้นมาให้หัวหน้าดู ไม่หลุดไปเงียบ ๆ

03
เห็นกำไรจริง แล้วเทียบกับที่สัญญาไว้

หลังงานจบ ระบบดึงตัวเลขจริงจากบัญชีเดินงานมาเทียบ — รู้ว่าที่รับงานไป จบตรงตามที่คิดหรือไม่

04
วางทับของเดิม ไม่ต้องรื้อ

อ่านจากฐานข้อมูล ERP ที่ใช้อยู่ ไม่เปลี่ยนวิธีทำงานเดิม เริ่มใช้ได้โดยไม่กระทบระบบหลัก

เดินชมทั้งวงจรใน 7 คลิก

เปิดเรียงตามลำดับ จะเห็นข้อมูลไหลจากต้นน้ำถึงปลายน้ำ

  1. Rate — เทียบ 3 เจ้าบนเส้นทางเดียว เห็นเรทที่ใกล้หมดอายุ
  2. Quotation — เลือกทางเลือกให้ลูกค้า Good / Better / Best
  3. Booking Gate — เลือกงานที่กำไรตกจาก 10% เหลือ 4% ดูว่าทำไม
  4. Approval — อนุมัติงานนั้น แล้วเห็นสถานะเดินต่อ
  5. Dashboard — ตั้งวันแล้วเห็นใบเสนอราคาที่เริ่มเสี่ยง
  6. AI Search — พิมพ์คำถาม ได้คำตอบพร้อมอ้างอิง
  7. Margin Actual — ดูกำไรจริง สลับมุมแผนกขาย / คอนโซล
