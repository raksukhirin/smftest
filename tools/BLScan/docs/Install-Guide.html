BLScan — คู่มือติดตั้ง

โปรแกรมอ่านใบ House B/L (PDF หรือรูป) แล้วส่งข้อมูลเข้า SMF — อ่านเอกสารนี้ก่อนใช้งานครั้งแรก

1ไฟล์ที่ได้รับ

ไฟล์หน้าที่
BLScan.exeโปรแกรม (ไม่ต้องติดตั้ง วางไว้โฟลเดอร์ใดก็ได้ แล้วดับเบิลคลิก)
templates\แบบ (Template) ของใบ B/L แต่ละผู้ออก ต้องวางอยู่ข้าง BLScan.exe ห้ามเปลี่ยนชื่อโฟลเดอร์
Install-Guide.htmlเอกสารนี้
ไฟล์ BLScan.ini จะถูกสร้างอัตโนมัติเมื่อบันทึกค่าในขั้นตอนที่ 3 ไม่ต้องคัดลอกมาจากเครื่องอื่น (คัดลอกมาก็ใช้ไม่ได้ เพราะรหัสผ่านที่เก็บไว้ผูกกับเครื่องที่ตั้งค่า)

2ตรวจความพร้อมของเครื่อง

  • Windows 10 หรือ 11 (โปรแกรมใช้ตัวอ่านข้อความ OCR และตัวเปิด PDF ที่มากับ Windows)
  • .NET Framework 4.x — มากับ Windows อยู่แล้ว ไม่ต้องติดตั้งเพิ่ม
  • ภาษา OCR ภาษาอังกฤษ (English United States) — ดูวิธีตรวจและติดตั้งด้านล่าง
  • เครื่องต่อเครือข่ายถึงเซิร์ฟเวอร์ฐานข้อมูล SMF ได้

วิธีตรวจว่ามีภาษา OCR ภาษาอังกฤษหรือยัง

วิธี ก — ใน Settings (Windows 11)

  1. เปิด Settings → Time & language → Language & region
  2. ในรายการ Preferred languages หา English (United States) ถ้าไม่มี กด Add a language แล้วเลือกเพิ่ม
  3. กดจุดสามจุดข้างชื่อภาษา → Language options
  4. ในรายการ Language features ต้องมี Optical character recognition และขึ้นว่า Installed ถ้ายังไม่มี ให้กดติดตั้งตรงนั้น แล้วรอจนเสร็จ

Windows 10: Settings → Time & Language → Language เลือก English (United States) → Options แล้วดูหัวข้อ Language pack features ในแนวเดียวกัน

วิธี ข — ใช้ PowerShell (คลิกขวาที่ PowerShell → Run as administrator)

Get-WindowsCapability -Online | Where-Object Name -like 'Language.OCR*en-US*'

ถ้าสถานะ (State) เป็น Installed แปลว่าพร้อมใช้งาน ถ้าเป็น NotPresent ให้ติดตั้งด้วยคำสั่งนี้ (ต้องต่ออินเทอร์เน็ต)

Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~~~0.0.1.0"
ถ้าไม่ได้ติดตั้ง ตอนกด Scan โปรแกรมจะแจ้งว่า "Windows OCR ไม่มีภาษา en-US — ติดตั้ง language pack ใน Settings > Time & Language" ให้ทำตามวิธีด้านบน แล้วปิดและเปิดโปรแกรมใหม่

3ตั้งค่าการเชื่อมต่อฐานข้อมูล (ทำครั้งเดียว)

  1. ดับเบิลคลิก BLScan.exe ที่แถบล่างจะขึ้นว่า "DB: ยังไม่ได้ตั้งค่า"
  2. กดปุ่ม ตั้งค่า DB… แล้วกรอก Server, ฐานข้อมูล, User และ Password ตามที่ผู้ดูแลระบบของคุณให้มา (หรือติ๊ก ใช้ Windows Authentication ถ้าใช้บัญชี Windows เชื่อมต่อ)
  3. กด ทดสอบเชื่อมต่อ แล้วกด บันทึก
  4. เมื่อตั้งค่าถูกต้อง แถบล่างจะขึ้น "DB: เชื่อมต่อแล้ว ✓"
รหัสผ่านถูกเก็บในไฟล์ BLScan.ini แบบเข้ารหัสและผูกกับเครื่องนี้ ถ้านำโปรแกรมไปติดตั้งเครื่องอื่น ต้องตั้งค่าใหม่ในเครื่องนั้นเอง
หน้าจอและไฟล์ log ของโปรแกรมจะไม่แสดงรายละเอียดเซิร์ฟเวอร์ (แสดงเฉพาะชื่อเซิร์ฟเวอร์เท่านั้น)

4ทดลองใช้งาน

  1. ใน SMF เพิ่ม House B/L ว่าง ได้เลข HB/L Ref
  2. ใน BLScan กด เลือกไฟล์… เลือกใบ B/L แล้วเลือก Template ให้ตรงกับผู้ออกใบ
  3. กด ▶ Scan ตรวจผลที่แสดง แล้วใส่เลข HB/L Ref
  4. กด Update DB → ตรวจข้อความยืนยัน → Yes

โปรแกรมเขียนเฉพาะ House B/L ที่สร้างรอไว้ด้วยเลข HB/L Ref นั้น ไม่สร้าง House B/L ใหม่ ช่องที่ Scan ไม่ได้ค่าจะไม่ทับค่าเดิม และไม่มีการลบข้อมูล

5Template และผู้ดูแล (Admin)

  • Template ที่แจกมากับโปรแกรมอยู่ในโฟลเดอร์ templates ข้าง BLScan.exe
  • ถ้าหลายเครื่องต้องใช้ Template ชุดเดียวกัน ตั้งโฟลเดอร์กลางได้ที่ ตั้งค่า DB… → แท็บ Template / Admin
  • ผู้ใช้ทั่วไปเลือกใช้ Template ได้อย่างเดียว การเพิ่ม/แก้/ลบ Template ใช้ Template Designer เฉพาะผู้ดูแล (ผู้ใช้ admin) ครั้งแรกให้ตั้งรหัสผ่าน admin ของตนเองในแท็บ Template / Admin (อย่างน้อย 8 ตัวอักษร)

6แก้ปัญหาเบื้องต้น

อาการวิธีแก้
"Windows OCR ไม่มีภาษา en-US …"ติดตั้งภาษา OCR ตามข้อ 2 แล้วเปิดโปรแกรมใหม่
แถบล่างขึ้น "DB: ยังไม่ได้ตั้งค่า" หรือ "เชื่อมต่อไม่ได้ ✗"ตรวจค่าใน "ตั้งค่า DB…" และตรวจว่าเครื่องต่อเครือข่ายถึงเซิร์ฟเวอร์ได้
"ไม่พบ HB/L Ref นี้ในระบบ"ตรวจเลขที่พิมพ์ และตรวจว่าสร้าง House B/L ว่างใน SMF แล้ว
Template ไม่ขึ้นหรือรายการว่างตรวจว่าโฟลเดอร์ templates อยู่ข้าง BLScan.exe และมีไฟล์ .json อยู่ข้างใน
อ่านใบแล้วบางช่องว่างหรือผิดตรวจว่าเลือก Template ตรงผู้ออกใบ และแก้ค่าในช่องด้านขวาก่อนกด Update DB
