## golden 3 ชุดคืออะไร

ผู้ใช้แก้ข้อมูลใน `smfdb` ระหว่างทางเพื่อทดสอบสูตร (แก้ค่าในแถวเดิม ไม่ใช่แค่เพิ่มแถว)
ทุกบรรทัดจึงเก็บค่า ณ วันพิมพ์รายงานแต่ละฉบับไว้กับตัวเองที่ `PRINT` / `PRINT2`
→ engine **ย้อนสถานะกลับไปคำนวณใหม่ได้** = มี golden หลายชุดจาก job เดียว

| snapshot | สถานะข้อมูล | เทียบกับ |
|---|---|---|
| **A** | ก่อนแก้อะไร | Profit Summary ฉบับ 22/07/2026 |
| **B** | ปิดการเฉลี่ย + เพิ่ม 2 บรรทัด | รายงานฉบับที่ 2 |
| **C** | เปิดเฉลี่ยกลับ (กรณี 3.1 + basis CBM) | รายงานฉบับที่ 3 |

| ที่ §03 | |
|---|---|
