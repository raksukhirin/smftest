# BLScan

Scan House B/L (PDF / JPG / PNG / TIF) → text (Windows OCR) → preview เป็น HTML ทรง House B/L → **UPDATE** record ที่สร้างรอไว้ใน SMF DB (`SFHBL` + `SFMARK`)

## Build / Run
```
build.bat            → bin\BLScan.exe + bin\BLScan.ini   (ใช้ csc ของ .NET Framework 4 ที่มากับ Windows)
```
ตั้งค่า DB ใน `bin\BLScan.ini` (`[Database]` Server / Database / User / Password — เว้น User ว่าง = Windows auth) · `bin/` ไม่เข้า git

| การใช้งาน | คำสั่ง |
|---|---|
| หน้าจอ | `BLScan.exe` หรือ `BLScan.exe <ไฟล์> /docno BLE26100001` (scan ทันที) |
| ไม่มีหน้าจอ | `BLScan.exe /scan <ไฟล์> /out <โฟลเดอร์> /docno X [/dryrun \| /update]` → `preview.html`, `fields.txt`, `changes.txt`, `ocr.txt`, `log.txt` |

## Template (ผังฟอร์มของผู้ออก B/L)
- **1 Template = 1 ผู้ออก** เป็นไฟล์ JSON ใน `templates\` ข้าง exe (ตั้งโฟลเดอร์อื่นได้ที่ ini `[Templates] Path=`) · โปรแกรมเริ่มต้นด้วย "ทั่วไป (ไม่ได้จูน)" ที่อยู่ในโค้ด
- **ใช้งาน:** เลือก Template ในดรอปดาวน์ **ก่อน Scan** (จำค่าล่าสุดให้) → หลัง Scan โปรแกรมตรวจว่าไฟล์มีคำระบุผู้ออก (`identify`) ของ Template นั้นไหม ถ้าไม่มีจะเตือนเป็นสีแดง บอกว่าไฟล์น่าจะเป็นฟอร์มของใคร และ **ปิดปุ่ม Update** จนกว่าจะเลือกถูก (เปลี่ยน Template แล้วอ่านซ้ำจาก OCR เดิมทันที ไม่ต้อง OCR ใหม่)
- **เนื้อหา Template:** `identify` (คำระบุผู้ออก) · `labels` (คำเรียกหัวช่องเพิ่ม) · `zones` (โซนสำรองเมื่อ OCR อ่านหัวช่องไม่ออก; y = ขอบบนที่ข้อความของช่องเริ่ม) · `strip` (ข้อความประกอบหัวช่องที่ตัดทิ้ง) · `terms` (เช่น `CFS-CFS` → `CFS/CFS`) · `dateFormats` (เช่น `yyyy/MM/dd`)
- **ชุดเฉลย:** `tests\golden.json` — ไฟล์ตัวอย่าง + ค่าที่ถูกต้อง รัน `BLScan.exe /testgolden tests\golden.json /templates templates /out <dir>` ได้ `golden.txt` (exit 0 = ผ่านทั้งหมด) ต้องรันทุกครั้งที่แก้ตัวอ่านหรือ Template
- **ส่วนที่แก้ที่ตัวโปรแกรม (ได้ทุก Template):** วันที่ `yyyy/MM/dd`, ตัวเลขที่ OCR เว้นวรรคหลังจุด/อ่าน 0 เป็น O และ 1 เป็น I, ตัวอักษรแตกรอบ I เฉพาะแถวฟอนต์ตัวกว้างเท่ากัน, หัวช่องที่พิมพ์แตกหลายบรรทัด, ตัดย่อหน้าเงื่อนไขการขนส่ง, ขอบคอลัมน์ในตารางสินค้า, OCR 2 ความละเอียดเพื่อซ่อมคำที่ถูกตัดท้าย (`[OCR] SecondScale`)
- **ด่านตรวจก่อน Update:** ค่าน่าสงสัย (วันที่ผิดปี, CBM ไม่มีทศนิยม, หัวช่องหลุดเป็นค่า, ข้อความยาวผิดปกติ) ขึ้นเตือนในกล่องยืนยันและแท็บ Log

### Template Designer (เฉพาะ admin)
ปุ่ม **Template Designer…** บนหน้าหลัก — ต้องเป็นโฟลเดอร์ Template ที่เปิดและเขียนได้ แล้วเข้าสู่ระบบ admin (ถ้าโฟลเดอร์เป็นอ่านอย่างเดียว/เปิดไม่ได้ จะบอกและไม่ให้เข้า)
1. **เปิดใบตัวอย่าง** (PDF/รูป, เลือกหน้าได้) → OCR → ตัวอ่านใช้ Template ที่กำลังแก้ทันที แล้ว **วาดกรอบซ้อนบนภาพ**: หัวช่องที่พบ (เขียว), ข้อความที่ตัวอ่านจับเข้าแต่ละช่อง (สีตามช่อง), โซนสำรอง (ส้มประ)
2. **หัวช่อง / โซน:** เลือกช่องในรายการ (แดง = ไม่พบหัวช่อง) แล้ว
   - *เลือกคำ* บนภาพ (คลิก/ลากกรอบ, Ctrl เพิ่ม) → **เพิ่มคำที่เลือกเป็นหัวช่อง** หรือพิมพ์คำเรียกในกล่องเอง
   - *ลากโซน* บนภาพ → ตั้งโซนสำรองของช่อง (ขอบบนของกรอบ = ที่ข้อความของช่องเริ่ม) ใช้เมื่อ OCR อ่านหัวช่องไม่ออก
3. **เตรียมลงฐานข้อมูล:** พิมพ์ค่าที่ถูกต้อง เห็น ✓/✗ ทันที (ปุ่มคัดลอกค่าที่อ่านได้มาเป็นเฉลยแล้วแก้เฉพาะที่ผิด)
4. **ทั่วไป:** คำระบุผู้ออก (เลือกบนภาพได้), ข้อความตัดทิ้ง, คำแปลง CY (`CFS-CFS => CFS/CFS`), รูปแบบวันที่
5. **ตัวอย่าง / ทดสอบ:** บันทึกใบพร้อมเฉลยไว้กับ Template (`_samples\<id>\`) แล้ว **ทดสอบทุกตัวอย่าง** ด้วยฉบับที่กำลังแก้ ก่อนบันทึก (ควรมี 2-3 ใบต่อ Template เพื่อพิสูจน์ว่าไม่จูนกับใบเดียว)
6. **บันทึก Template:** เลขเวอร์ชันเพิ่มเอง, สำรองฉบับเดิมไว้ใน `_trash`, ถ้า admin อีกคนแก้ไปก่อนจะไม่เขียนทับ
- ภาพ: ซูมด้วย **Ctrl + ล้อเมาส์** หรือปุ่ม − + / พอดีความกว้าง · เลื่อนภาพด้วยปุ่มกลาง/ขวาของเมาส์ลาก

### ที่เก็บ Template กลาง และ admin
- **ค่าเริ่มต้น** `templates\` ข้าง exe · **โฟลเดอร์กลาง:** ตั้งในหน้า "ตั้งค่า → Template / Admin" (ini `[Templates] Path=`) มีปุ่มทดสอบโฟลเดอร์ (อ่านได้/เขียนได้/มีรหัส admin ไหม)
- **สำเนาสำรอง:** เมื่อโหลดจากโฟลเดอร์กลางสำเร็จ โปรแกรมทำสำเนาไว้ที่ `templates\_cache\` แบบกระจกเงา (ไฟล์ที่ถูกลบจากโฟลเดอร์กลางก็หายจากสำเนา) ถ้าเปิดโฟลเดอร์กลางไม่ได้ จะใช้สำเนาล่าสุด แล้วแถบสถานะขึ้น "สำเนาสำรองในเครื่อง ⚠"
- **ผู้ใช้ทั่วไปแก้ Template ไม่ได้:** ไม่มีทางเข้าแก้ไขในโปรแกรม จัดการได้เฉพาะ admin
- **admin:** ผู้ใช้ตายตัว `admin` รหัสผ่านเก็บเป็น hash+salt (PBKDF2) ใน `admin.json` ในโฟลเดอร์ Template เดียวกัน → หลายเครื่องที่ชี้โฟลเดอร์กลางเดียวกันใช้รหัสเดียวกัน
  - ครั้งแรก (ยังไม่มี `admin.json`) ตั้งรหัสผ่านได้ในหน้าตั้งค่า (≥ 8 ตัวอักษร) · ใส่ผิด 3 ครั้งติดจะถูกล็อก 30 วินาที (เพิ่มเป็นสองเท่า สูงสุด 10 นาที) · สิทธิ์ admin หมดเมื่อปิดหน้าตั้งค่า
  - admin ทำได้: เปลี่ยนรหัสผ่าน, นำเข้า Template (ตรวจรูปแบบก่อน; id ซ้ำต้องยืนยัน และสำรองไฟล์เดิมไว้), ลบ Template (ย้ายไป `_trash\` กู้คืนได้)
  - เขียน Template แบบอะตอมมิก และตรวจเลขเวอร์ชัน — ถ้า admin อีกคนแก้ไฟล์เดียวกันไปก่อน จะไม่ยอมเขียนทับ
- **ข้อจำกัดที่ต้องรู้:** รหัสผ่านกันได้เฉพาะ "ผ่านหน้าจอโปรแกรม" ผู้ที่มีสิทธิ์เขียนโฟลเดอร์กลางยังแก้ไฟล์ JSON หรือลบ `admin.json` ด้วยมือได้ **การกันจริงต้องตั้งสิทธิ์โฟลเดอร์กลางเป็นอ่านอย่างเดียวสำหรับผู้ใช้ทั่วไป และเขียนได้เฉพาะ admin** (โปรแกรมตรวจเจอว่าโฟลเดอร์เป็นอ่านอย่างเดียวแล้วจะซ่อนปุ่ม admin ให้เอง)
- **ลืมรหัสผ่าน:** ผู้ที่เข้าถึงโฟลเดอร์กลางได้ลบ `admin.json` แล้วตั้งใหม่
- **ทดสอบ:** `tests\run-tests.bat` (ที่เก็บ Template/admin 33 ข้อ + ชุดเฉลยการอ่านฟอร์ม)

## ตั้งค่า DB (เข้ารหัสรหัสผ่านใน ini)
- ในโปรแกรมกดปุ่ม **ตั้งค่า DB…** → กรอก Server / Database / User / Password (หรือเลือก Windows Authentication) → **ทดสอบเชื่อมต่อ** → **บันทึก**
- รหัสผ่านถูกเข้ารหัสด้วย **Windows DPAPI แบบผูกกับ "เครื่อง" (LocalMachine)** แล้วเก็บเป็น `Password=encm:<base64>` — ถ้ามี `ConnectionString` เต็มใน ini ก็เข้ารหัสแบบเดียวกัน
- **ไม่มีหน้า login** — ผู้ใช้ Windows คนไหนบนเครื่องที่ตั้งค่าไว้ก็เปิด exe ใช้ได้เลย
- **ก๊อป ini ไปเครื่องอื่นแล้วใช้ไม่ได้** จนกว่าจะกด "ตั้งค่า DB…" ผ่านโปรแกรมนี้ที่เครื่องนั้น (แถบสถานะจะแจ้งว่าถอดรหัสไม่ได้)
- ini เดิมที่เก็บรหัสผ่านเป็นข้อความธรรมดา (หรือ `enc:` รุ่นผูกผู้ใช้) ยังอ่านได้ — แปลงเป็น `encm:` ด้วย `BLScan.exe /encryptini` (หรือกดบันทึกในหน้าตั้งค่า) · เขียน ini แล้วคง comment/ลำดับเดิมไว้
- ข้อจำกัด: เพราะผูกกับเครื่อง ใครก็ตามที่ login เข้าเครื่องนั้นได้ (หรือรันโปรแกรมบนเครื่องนั้น) ถอดรหัสผ่านได้ — กันเฉพาะการก๊อปไฟล์ ini ออกไปนอกเครื่อง

## กติกา Update
1. สร้าง `SFHBL` record รอไว้ก่อน (DOCNO = key) — โปรแกรม**ไม่ INSERT SFHBL** ถ้าไม่พบ DOCNO จะปฏิเสธ · DOCNO ว่าง = ปฏิเสธ
2. `UPDATE SFHBL ... WHERE DOCNO=@d` (ไม่ตรวจ LOCK แต่ตั้ง `LOCK=CDbl(Now)`, `EDITBY`, `EDITDATE` ใหม่เหมือน frmSFBL)
   - เขียนเฉพาะช่องที่ scan ได้ค่า — ช่องว่างไม่ไปทับค่าเดิม · ไม่แตะ DOCNO/JOBNO/DOCDATE/MASTERNO/JOBCLASS/JOBTYPE/LOADTYPE/DOCSTAT/USERID
   - งาน EX: `ETDETA = ETD`
   - คู่ค้า (Shipper/Consignee/Notify/Agent): ชื่อ = **บรรทัดแรกของข้อความที่ scan ได้** → หารหัสใน `SMBUSINESS.COMNAME` (เจอหลายรหัส = ตัวแรก active ก่อน แล้วเรียง COMNO)
     - พบ → รหัสที่พบ + ชื่อ + ที่อยู่ (`S_ADD`/`C_ADD`/`N_ADD`/`A_ADD`) ที่ scan ได้
     - ไม่พบ + record เดิม**ว่าง** (รหัสและชื่อว่างทั้งคู่) → รหัส `N/A`, ชื่อ = บรรทัดแรก, ที่อยู่ = ที่ scan ได้
     - ไม่พบ + record เดิม**ไม่ว่าง** → คงรหัส/ชื่อเดิม เปลี่ยนเฉพาะที่อยู่ = ที่ scan ได้
   - รหัสท่า: จาก HBL อื่นของงานเดียวกัน → `OPPORT` (`PORTTYPE='SF'`, ชื่อตรง หรือขึ้นต้นด้วยชื่อ + `,` เลือกรหัส 5 ตัวที่ไม่กำกวม) · หน่วย → `SMUOM`
   - `PKGWORD` เก็บตามที่ scan ได้
   - `CTNLIST` (SFHBL.CTNLIST, ชนิด text) เก็บเลขตู้คอนเทนเนอร์มาตรฐาน (ตัวอักษร 4 ตัวลงท้าย U/J/Z + เลข 7 หลัก เช่น `CAAU8035430`) บรรทัดละ 1 เลข จากช่อง Container No./Marks; ถ้า Template ตั้ง "กรอบดึงค่า" ของ CTNNO ไว้ จะเก็บตามที่ scan ได้ในกรอบนั้น — ค่าเดียวกันนี้เขียนลง `SFMARK.CTNLIST` (แถวแรก) ด้วย
3. `SFMARK` (HBLREF = DOCNO): ไม่มี → INSERT 1 แถว · มี → UPDATE **แถวแรก** (SEQNO, DETID) ไม่ว่ามีกี่แถว
4. 2 ตารางอยู่ใน transaction เดียว — พลาดแล้ว rollback ทั้งหมด · โปรแกรมไม่มีการลบข้อมูล (ไม่มีคำสั่ง DELETE)
5. **Dry run** = UPDATE จริงทุกขั้นแล้ว ROLLBACK
6. `ReferenceDocNo` ใน ini (ตอนนี้ `SI17110002/005`) = record อ้างอิง ใช้เทียบอย่างเดียว โปรแกรมไม่ยอมเขียน (dry run ได้)
7. บันทึกสำเร็จจะต่อท้าย `BLScan.log` ข้าง exe พร้อมรายการ ก่อน → หลัง
8. log ทุกแห่ง (`BLScan.log`, แท็บ Log, `log.txt`) และหน้าจอ **ไม่แสดงรายละเอียดการเชื่อมต่อ** — ลงแค่ชื่อ server (ไม่มี port/database/user/รหัสผ่าน) และข้อความ error ของ SQL จะถูกกรองส่วนเหล่านี้ออกเป็น `***`
